# فصل ۵ — فایل و جستجو در پروژه

## باز کردن فایل (Double Shift وب‌استورم)

| کلید | کار |
|---|---|
| `<leader>ff` | جستجوی فایل در پروژه (fuzzy، حتی hidden) |
| `<leader>fr` | فایل‌های اخیر |
| `<leader>fb` | بین بافرهای باز |
| `<leader>e` | اکپلورر (neo-tree) |

## جستجوی متن (Ctrl+Shift+F وب‌استورم)

| کلید | کار |
|---|---|
| `<leader>fg` | جستجوی متن در کل پروژه (ripgrep) |
| `<leader>fw` | جستجوی کلمه زیر کرسر در پروژه |
| `<leader>f/` | جستجو فقط در فایل جاری |

مسترشد این است: بعد از `<leader>fg`، عبارت را بنویسید؛ در نتایج `Ctrl+j/k` حرکت، `Enter` باز کردن، `Tab` ارسال چند نتیجه به quickfix (بعد `:cdo s/قدیم/جدید/g` = جایگزینی گروهی!).

## جستجو و جایگزینی در پروژه (Replace in Path وب‌استورم)

| کلید | کار |
|---|---|
| `<leader>sr` | Spectre: جستجو/جایگزینی با پیش‌نمایش در کل پروژه |
| `<leader>sw` | همین، با کلمه زیر کرسر |

در Spectre: روی هر نتیجه `Enter` = جایگزینی تک‌نمونه؛ `?` برای همه دستورات؛ دکمه **Replace all** هم هست. فیلتر glob و مسیر هم دارد.

## Symbol ها (Ctrl+F12 وب‌استورم)

| کلید | کار |
|---|---|
| `<leader>ss` | توابع/کلاس‌های فایل جاری |
| `<leader>sS` | توابع/کلاس‌های کل پروژه |

## جاهای دیگر که Telescope هست

| کلید | کار |
|---|---|
| `<leader>fh` | راهنمای help |
| `<leader>sk` | جستجو بین همه کلیدهای میانبر |
| `<leader>sc` | همه دستورات |
| `<leader>fc` | هیستوری دستورات |
| `<leader>gu` | وضعیت گیت (فایل‌های تغییرکرده + unversioned) |
| `<leader>gc` / `<leader>gb` | کامیت‌ها / برنچ‌ها |
| `<leader>ut` | انتخاب تم (فصل ۱۰) |
| `<leader>hU` | هیستوری undo (فصل ۸) |
| `<leader>hl` | Local History (فصل ۸) |

نکته‌های Telescope: `Ctrl+j/k` حرکت، `Ctrl+u/d` اسکرول پیش‌نمایش، `Esc` بستن.
