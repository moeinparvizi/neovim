# فصل ۳ — مدیریت پنجره، بافر و تب

## مفهوم: بافر ≠ پنجره ≠ تب

- **Buffer**: یک فایل باز در حافظه (وب‌استورم: تب ادیتور)
- **Window**: یک قاب نمایش (وب‌استورم: split)
- **Tab**: یک چیدمان از پنجره‌ها (وب‌استورم: پروژه/workspace)

نوار بالای صفحه (bufferline) = تب‌های ادیتور وب‌استورم شماست.

## جابجایی بین پنجره‌ها

| کلید | کار |
|---|---|
| `Ctrl+h/j/k/l` | چپ / پایین / بالا / راست (در ترمینال هم کار می‌کند!) |
| `<leader>ww` | چرخش بین پنجره‌ها |

## ساخت و بستن اسپلیت

| کلید | کار |
|---|---|
| `<leader>wv` | اسپلیت عمودی |
| `<leader>ws` | اسپلیت افقی |
| `<leader>wq` | بستن پنجره |
| `<leader>wo` | بستن بقیه پنجره‌ها (فقط این) |
| `<leader>w=` | هم‌اندازه کردن همه |

## تغییر اندازه

| کلید | کار |
|---|---|
| `Ctrl+Up/Down` | بلندتر/کوتاه‌تر |
| `Ctrl+Left/Right` | پهن‌تر/باریک‌تر |

## جابجایی خود پنجره (مثل درگ)

| کلید | کار |
|---|---|
| `<leader>wH` | پرت کردن پنجره به چپِ کل |
| `<leader>wJ` | به پایینِ کل |
| `<leader>wK` | به بالای کل |
| `<leader>wL` | به راستِ کل |

## بافرها (تب‌های ادیتور)

| کلید | کار |
|---|---|
| `Shift+h` / `Shift+l` | تب قبلی / بعدی |
| `<leader>1..9` | پرش به بافر شماره |
| `<leader>bb` | بافر قبلی (alternate) |
| `<leader>bd` | بستن بافر (بدون خراب کردن layout) |
| `<leader>bo` | بستن بقیه بافرها |
| `<leader>fb` | جستجوی fuzzy بین بافرها |
| `<leader>bp` / `<leader>bP` | پین / انتخاب بافر |

## تب‌ها

| کلید | کار |
|---|---|
| `:tabnew [فایل]` | تب جدید |
| `gt` / `gT` | تب بعدی / قبلی |
| `:tabonly` | بستن بقیه تب‌ها |

## ترمینال

| کلید | کار |
|---|---|
| `Ctrl+/` | ترمینال شناور (toggle) |
| `<leader>th` | ترمینال افقی پایین |
| `<leader>tv` | ترمینال عمودی |
| `<leader>ts` | انتخاب بین ترمینال‌های باز |
| `Esc` | خروج از حالت ترمینال (حرکت با کلیدهای نرمال) |

داخل ترمینال هم `Ctrl+h/j/k/l` برای پرش بین پنجره‌ها کار می‌کند.

## اکپلورر فایل

| کلید | کار |
|---|---|
| `<leader>e` | باز/بستن اکپلورر |
| `<leader>ge` | پنجره git status شناور (فایل‌های unversioned هم اینجا!) |
| `<leader>be` | لیست بافرها شناور |

داخل neo-tree: `l` باز کردن، `h` بستن فولدر، `a` فایل جدید، `d` حذف، `r` rename، `y/x/p` کپی/برش/پیست، `P` پیش‌نمایش.

> فایل جدید با مسیر تودرتو بسازید: `a` → `src/components/Header.tsx` — پوشه‌ها خودکار ساخته می‌شوند (حتی موقع ذخیره).
