# فصل ۴ — ادیتینگ حرفه‌ای

## مولتی‌کرسر (Ctrl+Click وب‌استورم)

| کلید | کار |
|---|---|
| **Ctrl+Click** | اضافه کردن کرسر جدید روی همون نقطه (دقیقاً عین وب‌استورم!) |
| `Ctrl+n` | اضافه کردن کرسر روی تطبیق بعدی کلمه زیر کرسر (مثل Ctrl+G وب‌استورم) |
| `Ctrl+Down` / `Ctrl+Up` | اضافه کردن کرسر یک خط پایین/بالا (Alt+Shift+Click وب‌استورم) |
| `Esc` | برگشت به تک‌کرسر |

حالا هرچه تایپ/حذف می‌کنید روی همه کرسرها همزمان اعمال می‌شود. برای rename متغیرهای ساده سریع‌تر از LSP است؛ برای rename هوشمند (مثل Shift+F6) از `<S-F6>` فصل ۶ استفاده کنید.

## Flash — پرش نورانی داخل فایل

| کلید | کار |
|---|---|
| `s` + ۲ حرف | پرش به هر جای فایل‌های باز (لیبل‌دار) |
| `S` | انتخاب هوشمند Treesitter node |
| `r` (در حالت operator) | عملیات روی جای دور: مثلاً `yr`+مقصد = yank از مقصد |
| `/` | جستجوی معمولی، ولی با لیبل‌های پرش |

چرخه کار سریع: `d` برای حذف؟ نه — `ds`+مقصد. کپی؟ `ys`+مقصد.

## کامنت‌گذاری (Ctrl+/ و Ctrl+Shift+/ وب‌استورم)

| کلید | کار |
|---|---|
| `gcc` | کامنت/آن‌کامنت خط جاری |
| `gc` + موشن | کامنت محدوده: `gcap` = کل پاراگراف، `gcG` = تا آخر فایل |
| `gc` در Visual | کامنت انتخاب |

هوشمند است: در JSX از `{/* */}` و در `<script>` از `//` و در HTML از `<!-- -->` خودش استفاده می‌کند (ts-context-commentstring).

## اطراف (Surround) — مدیریت براکت و گیومه

| کلید | کار |
|---|---|
| `sa` + آبجکت + کاراکتر | افزودن: `saiw"` → کلمه در گیومه؛ `saa)` |
| `sd` + کاراکتر | حذف اطراف: `sd"` |
| `sr` + قدیم + جدید | تعویض: `sr")` → گیومه‌ها پرانتز می‌شوند |
| `sh` / `sf` / `sF` | هایلایت / پیدا کردن اطراف |

کاربرد روزمره: `cs` نیست، `sr` است — بعد از یک روز می‌چسبد!

## ترازبندی (align)

- `ga` + کاراکتر در Visual: `=`ها یا `:`های چند خط را زیر هم می‌آورد (mini.align، تعاملی).

## تگ‌های HTML/JSX

- nvim-ts-autotag: تگ را که می‌بندید `</div>` خودکار می‌آید؛ و **rename تگ باز، تگ بسته را هم عوض می‌کند**.
- emmet_ls: در حالت درج بنویسید `div.container>ul>li*3` و بعد `Ctrl+y ,` (بستگی به سرور) — HTML تولید می‌شود.

## جابجایی خطوط (Alt+Shift+Up/Down وب‌استورم)

| کلید | کار |
|---|---|
| `J` / `K` در Visual | خطوط انتخابی پایین/بالا |

## پایه‌های بیشتر

| کلید | کار |
|---|---|
| `Ctrl+a` / `Ctrl+x` | افزایش/کاهش عدد زیر کرسر |
| `~` | تغییر بزرگ/کوچکی حرف |
| `gU` / `gu` / `g~` + موشن | uppercase / lowercase / برعکس |
| `>` / `<` در Visual | تورفتگی |
| `J` | چسباندن خط بعدی |
| `za` / `zo` / `zc` | باز/بستن فولد (فصل ۱۲) |
