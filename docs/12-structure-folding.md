# فصل ۱۲ — ساختار (Structure) و فولدینگ

## پنل Structure — `<leader>o` (Aerial)

مثل Structure tool window وب‌استورم: درخت توابع، کلاس‌ها، متغیرها، تگ‌ها و... در سایدبار راست.

- `Enter` پرش به symbol
- حرکت با `j/k` — پیش‌نمایش زنده
- `<leader>co` = ناوبر شناور کل فایل (برای فایل‌های بزرگ عالی است)
- `<leader>ss` = همان به شکل fuzzy search

منبع داده: اول LSP، بعد Treesitter — یعنی برای TS/JS/انگولار دقیق است.

## Breadcrumbs (نوار بالای پنجره)

بالای هر فایل، مسیر symbol ها نشان داده می‌شود (مثلاً `src > app > UserService > getUser`). با `<leader>;` حالت pick: روی مسیر حرکت کنید و به هر symbol بپرید؛ منوی کشویی هم با کلیک باز می‌شود.

## فولدینگ — nvim-ufo

فولدینگ مبتنی بر LSP (دقیق‌ترین) با fallback به indent.

| کلید | کار |
|---|---|
| `za` | باز/بستن فولد زیر کرسر |
| `zR` | باز کردن همه فولدها |
| `zM` | بستن همه فولدها |
| `zr` / `zm` | باز/بسته کردن سطح‌به‌سطح |
| `zp` | پیش‌نمایش بدنه فولد بسته (بدون باز کردن!) |
| `zO` | باز کردن فولد و زیرفولدهایش |

فولد شده تعداد خطوط و محتوای خلاصه را نشان می‌دهد (مثل `▾ 25 lines ─ export function useAuth()`).

نکته: `foldlevel=99` یعنی فایل‌ها باز باز می‌شوند — مثل وب‌استورم. `zM` را صبح کار بزنید تا نمای کلی بگیرید.

## `z` های مفید دیگر

| کلید | کار |
|---|---|
| `zz` / `zt` / `zb` | وسط/بالا/پایین صفحه کردن خط جاری |
| `zj` / `zk` | فولد بعدی/قبلی |
