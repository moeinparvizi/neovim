# فصل ۱۱ — TODO و بوکمارک

## TODO ها (Task list وب‌استورم)

کلیدواژه‌های شناسایی‌شده در کامنت‌ها:

| کلیدواژه | معنی |
|---|---|
| `TODO:` | کار باقی‌مانده |
| `FIXME:` / `BUG:` / `FIX:` | چیز خراب |
| `HACK:` | راه‌حل موقت |
| `NOTE:` / `INFO:` | یادداشت |
| `PERF:` / `OPTIMIZE:` | بهینه‌سازی |
| `WARN:` / `XXX:` | هشدار |
| `TEST:` | تست |

همه با آیکون و رنگ در gutter هایلایت می‌شوند.

| کلید | کار |
|---|---|
| `<leader>st` | جستجوی fuzzy بین همه TODO های پروژه |
| `<leader>xt` | پنل Trouble: لیست TODO ها (مثل TODO tool window) |
| `]t` / `[t` | TODO بعدی/قبلی در فایل |

## بوکمارک‌ها (F11 وب‌استورم)

بوکمارک = مارک‌های ویم (به هر نقطه از هر فایل، یک حرف می‌چسبانند).

| کلید | کار |
|---|---|
| `m` + حرف | ثبت بوکمارک روی خط جاری (مثلاً `ma`) |
| `'` + حرف | پرش به بوکمارک (`'a`) — حتی بعد از بستن فایل |
| `` ` `` + حرف | پرش دقیق به کاراکتر |
| `mm` | toggle بوکمارک پیش‌فرض روی خط |
| `m;` | لیست همه بوکمارک‌ها با پیش‌نمایش (jump با Enter) |
| `dm` + حرف | حذف بوکمارک |
| `m[0-9]` | بوکمارک‌های شماره‌دار (تا ۱۰ تا، بین فایل‌ها مشترک) |

پلاگین marks.nvim آیکون بوکمارک را در gutter نشان می‌دهد و `m;` منوی زیبایش است.

## بوکمارک‌های داخلی ویم (خودکار)

| مارک | معنی |
|---|---|
| `` `. `` | آخرین تغییر |
| `` `" `` | جایی که فایل بسته شده بود (خودکار برگردانده می‌شود) |
| `` `^ `` | آخرین محل خروج از insert |
| `` `< `` / `` `> `` | ابتدا/انتهای آخرین انتخاب |
