# فصل ۱۳ — پشتیبانی فارسی (خیلی مهم!)

## تایپ فارسی داخل کد — F9

سیستم keymap داخلی ویم استفاده شده: **همان چیدمان استاندارد ISIRI 9147** که OS شما دارد؛ یعنی حروف همان‌جایی‌اند که روی کیبورد فیزیکی فارسی‌تان عادت دارید (ق/ص/ث/...).

| کلید | کار |
|---|---|
| `F9` (در حالت درج) | سوییچ فارسی ↔ انگلیسی — بدون ترک insert! |
| `:PersianOn` / `:PersianOff` / `:PersianToggle` | دستوری |
| نوار وضعیت | وقتی فارسی است، `فارسی` نارنجی نشان داده می‌شود |

- `Shift+B` = **نیم‌فاصله** (ZWNJ) — درست در چیدمان استاندارد (ذ ذخیره؟ نه، `b` = ذ و `Shift+b` = نیم‌فاصله، مطابق کیبورد ویندوز/مک)
- `Shift+Space`... و بقیه علائم (، ٪ × ÷ و...) هم مطابق چیدمان استاندارد map شده‌اند
- `Ctrl+^` هم معادل F9 است (میانبر ویم)
- در حالت command line (بعد از `:`) هم F9 کار می‌کند

نکته مهم: keymap فقط در حالت درج اثر دارد؛ حرکت‌ها (`j/k/w/b`, `dd`, `yy`...) همیشه انگلیسی‌اند — یعنی وسط متن فارسی هم می‌توانید مثل همیشه ادیت کنید.

## مقایسه با راه‌حل وب‌استورم

در وب‌استورم سوییچ زبان یعنی سوییچ کیبورد OS (Cmd+Space در مک). در ویم، سوییچ **داخل ادیتور** است و بقیه سیستم انگلیسی می‌ماند — عملاً سریع‌تر.

## نیم‌فاصله سریع در هر جا

| کلید | کار |
|---|---|
| `Alt+Space` (در insert) | درج مستقیم ZWNJ حتی وقتی keymap انگلیسی است |

## نمایش صحیح حروف (shaping)

ترمینال است که متن را رندر می‌کند:

- **kitty** / **WezTerm** / **iTerm2** — حروف چسبیده و RTL را درست نشان می‌دهند ✅
- Terminal.app مک — شکل‌دهی ضعیف ❌ (توصیه نمی‌شود)

اگر در kitty حروف جدا-جدا دیدید، این را به `kitty.conf` اضافه کنید:

```
symbol_map U+0600-U+06FF,U+200C-U+200F,U+FB50-U+FDFF,U+FE70-U+FEFF JetBrainsMono Nerd Font
```

## فونت

فونت اصلی **JetBrainsMono Nerd Font** است. برای فارسی خواناتر، فونت فارسی fallback اضافه کنید (kitty به ترتیب fallback می‌رود):

```
font_family      JetBrainsMono Nerd Font
bold_font        auto
italic_font      auto
bold_italic_font auto
# fallback خودکار برای فارسی:
symbol_map U+0600-U+06FF Vazirmatn
```

نصب وزیرمتن: `brew tap homebrew/cask-fonts && brew install --cask font-vazirmatn`

## متن راست‌به‌چپ (RTL)

- `:set rl` / `:set lrl` → پاراگراف/فایل راست‌به‌چپ برای نویسندگی فارسی (با `<leader>uw` برای wrap ترکیب کنید)
- برای کد، همان LTR بماند؛ کامنت‌های فارسی داخل کد LTR درست رندر می‌شوند (کلمات فارسی درست، جهت بیدای متنی LTR)

## جستجو در متن فارسی

`/` و `<leader>fg` و Spectre با متن UTF-8 فارسی کامل کار می‌کنند (ripgrep یونی‌کد است). فقط `smartcase` روی فارسی اثری ندارد (حروف بزرگ/کوچک ندارد).

## طومار (spell) فارسی

`:setlocal spell spelllang=fa` — لغت‌نامه فارسی (نیاز به دانلود خودکار دارد؛ `zg` اضافه کردن لغت).
