# فصل ۲ — مبانی Vim (موتور همه‌چیز)

WebStorm یک حالت دارد: تایپ می‌کنی یا ماوس می‌گیری. Vim سه حالت دارد و قدرتش از همین‌جاست:

| حالت | چی‌کار می‌کنه | چطور واردش شی |
|---|---|---|
| **Normal** | حرکت، حذف، کپی — پادشاه حالت‌ها | `Esc` |
| **Insert** | تایپ متن | `i` `a` `o` |
| **Visual** | انتخاب (مثل درگ ماوس) | `v` (کاراکتری) / `V` (خطی) / `Ctrl+v` (بلوکی) |

## فرمول طلایی: اپراتور + شماره + موشن

```
[count][operator][motion]
```

| اپراتور | معنی |
|---|---|
| `d` | delete (حذف → به رجیستر می‌ره = cut) |
| `c` | change (حذف + رفتن به حالت درج) |
| `y` | yank (کپی) |
| `p` / `P` | paste بعد/قبل از کرسر |

| موشن | معنی |
|---|---|
| `w` / `b` | کلمه بعدی / قبلی |
| `e` / `ge` | انتهای کلمه بعدی / فعلی |
| `0` / `$` | ابتدا / انتهای خط |
| `^` / `g_` | اولین / آخرین کاراکتر غیرخالی خط |
| `f` + x | پرش به اولین x در خط (`;` بعدی، `,` قبلی) |
| `t` + x | قبل از اولین x |
| `}` / `{` | پاراگراف بعدی / قبلی |
| `gg` / `G` | ابتدا / انتهای فایل |
| `%` | پرش به پرانتز/براکت/آکولاد جفت |
| `*` / `#` | کلمه زیر کرسر در فایل (بعدی/قبلی) |

پس `d2w` = حذف ۲ کلمه. `ci"` = تغییر محتوای داخل گیومه. `yap` = کپی کل پاراگراف.

## تکس‌آبجکت — سوپرقدرت Vim

| آبجکت | معنی |
|---|---|
| `iw` / `aw` | کلمه (داخلی / با فاصله) |
| `i"` `a"` | داخل گیومه / با گیومه |
| `i(` `a(` | داخل پرانتز / با پرانتز (همون `ib`/`ab`) |
| `i{` `a{` | داخل آکولاد (بدنه تابع/بلاک!) |
| `it` / `at` | تگ HTML/JSX (فقط محتوا / با تگ) |
| `ih` | **hunk گیت** (تغییرات بلاک جاری — با gitsigns) |

مثال واقعی: کرسر جایی داخل `console.log("hello")` است:
- `ci"` → متن داخل گیومه عوض می‌شه
- `da(` → کل `("hello")` پاک می‌شه
- `diw` → فقط `log` پاک می‌شه

## Undo / Redo — بازگشت به تغییرات قبل

| کلید | کار |
|---|---|
| `u` | برگرد به عقب (undo) |
| `Ctrl+r` | جلو برو (redo) |
| `U` | برگرداندن کل تغییرات آخرین خط |

چون `undofile` فعاله، **هیستوری حتی بعد از بستن nvim می‌مونه** (مثل Local History وب‌استورم).
برای دیدن گراف کامل هیستوری: `<leader>hu` (فصل ۸).

## جستجو داخل فایل

| کلید | کار |
|---|---|
| `/متن` | جستجو به جلو |
| `?متن` | جستجو به عقب |
| `n` / `N` | نتیجه بعدی / قبلی (خودکار وسط صفحه می‌شه) |
| `<leader>f/` | جستجوی fuzzy در فایل جاری |
| `Esc` | پاک کردن هایلایت |

> جستجوی `/` این کانفیگ با flash تقویت شده: حروف نتیجه‌ها را می‌بینید و با یک حرف می‌پرید.

## حرکت سریع با Flash (مثل AceJump / EasyMotion)

کلید `s` را بزنید و ۲ حرف از مقصد تایپ کنید — روی همه‌ی مکان‌های منطبق در **کل صفحه‌های باز** لیبل می‌افتد؛ حرف لیبل را بزنید تا بپرید. در حالت Visual هم کار می‌کند (انتخاب دور می‌زند) و در حالت Operator هم (`ds` بعد مقصد = حذف از کرسر تا مقصد).

`S` (بزرگ) = انتخاب Treesitter node: اسم تابع، آرگومان، تگ و… را هوشمند انتخاب می‌کند.

## رجیسترها — کلیپ‌بوردهای چندگانه

این کانفیگ کلیپ‌بورد سیستمی را به رجیستر `"+` وصل کرده (`clipboard=unnamedplus`)؛ یعنی کپی/پیست با سیستم‌عامل یکیه.

| کلید | کار |
|---|---|
| `"+y` | کپی به کلیپ‌بورد سیستم |
| `"ay` | کپی به رجیستر a (بعداً `"ap`) |
| `"_d` | حذف بدون به‌هم‌ریختن رجیستر (blackhole) |
| `:reg` | دیدن همه رجیسترها |
| `Ctrl+r` + حرف | درج محتوای رجیستر داخل حالت درج |

نکته: paste روی selection رجیستر را خراب نمی‌کند (در این کانفیگ `p` در visual حالت `"_dp` است).

## تمرین ۱۰ دقیقه‌ای

۱. یک فایل JS باز کنید. ۲. `ci{` را روی بلاک یک تابع امتحان کنید. ۳. `s` + دو حرف برای پرش. ۴. `u` و `Ctrl+r` را چند بار بزنید. ۵. `:help text-objects` را باز کنید (با `q` ببندید).
